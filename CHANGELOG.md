## [1.0.0]: 2026-08-17
First public release of the program.

### The program
- A 24 week curriculum in seven phases, with `curriculum/manifest.json` as the single
  source of truth for every week, objective, use case, and checklist
- One week folder per week: a study README, runnable notebooks, a Friday use case, a
  ten question quiz with a reasoned answer key, and exercise hints
- 43 runnable notebooks across Python, SQL, and PySpark
- One continuous case study, the fictional freight operator ZoroLogistics, generated
  from seeded code by the `zoro` toolkit so every machine produces the same rows
- An invariant from Week 3 on: no AI artifact is finished until it carries a metric and
  a short note on where it failed

### Reference
- A 14 file knowledge base: the AI engineering discipline (Ng's skills map and Zorost's
  systems spine), machine learning and deep learning, LLM internals, prompt and context
  engineering, retrieval and graphs, model engineering, evals and error analysis, local
  inference, harnesses, agents, MCP, cloud platforms, and Databricks
- Tool guides for Claude Code, Cursor, OpenCode, DeepSeek Harness, OpenRouter, and the
  Ollama and llama.cpp local stack
- Agent patterns: OpenClaw, Hermes, agent fundamentals, multi-agent orchestration, MCP
- Cloud platform modules for Azure AI Foundry, Google Vertex AI, and AWS Bedrock
- A Databricks zero to hero module, 00 to 18, ending in a lakehouse capstone bundle
- A glossary covering every term the program uses, in plain language

### Tooling and publication
- `START-HERE.md` at the root for readers new to programming or to AI
- An Excel progress tracker with one row per week and a dashboard, generated by
  `scripts/build_tracker.py`
- The program site published with GitHub Pages at zorost.github.io/AI-Engineering-Lab,
  generated from the manifest by `scripts/build_site.py` so the page cannot drift
- Checks: `scripts/check_notebooks.py`, `scripts/check_links.py`,
  `scripts/check_mermaid.py`, and `scripts/release_check.py`
- Diagrams authored at the width GitHub renders, so no label overlaps or clips
- MIT license, security policy, code of conduct, contributing guide, and roadmap
