# AI/ML Engineering Lab

A personal **AI/ML practice and experimentation repository by Shlok Mishra**, created to learn, implement, and document concepts across Machine Learning, Deep Learning, Data Science, Generative AI, and AI Engineering.

This repository is a continuous learning workspace where concepts are studied, implemented from scratch where practical, tested with small experiments, and organized into progressively more advanced topics.

## About

**AI/ML Engineering Lab** contains my implementations, practice problems, experiments, notebooks, and mini-projects covering:

- Python for AI/ML
- NumPy & Pandas
- Data Analysis & Visualization
- Machine Learning
- Feature Engineering
- Model Evaluation
- Deep Learning
- Computer Vision
- NLP
- Transformers
- Generative AI
- LLM Applications
- RAG
- AI Agents
- FastAPI & AI APIs
- MLOps fundamentals
